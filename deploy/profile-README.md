### 🫧 What GrokLevel is

```toml
[grok_level]
is = "a Grok teammate that reads a pump.fun launch before you do"
reads = "the bonding curve, the creator wallet, the top holders, the market, and then X through Grok"
answers = "counts and quotes in about ten seconds: posts, accounts, account ages, repeated text, the project's own account"
never = "a price call, a score, a buy button, a signer, a stored address"
costs = "about $0.10 of Grok per read, shown on every card"
ca = "3fK54p5SzHiPKB9JqPw893i1FNU5Xahf1QQbt4iPpump"
```

### ⚙️ One read

| Step | What happens |
|---|---|
| 📼 **Tape** | every pump.fun launch arrives the second it is created. A launch that reaches $25K while it is 3 to 180 minutes old is read unasked, up to 20 an hour |
| 🧷 **Curve** | the bonding curve account: who created it, how far along, graduated or not |
| 🧮 **Holders** | the 20 largest accounts resolved to owners and owning programs, so the curve and the pools are excluded from the top-10 share |
| 👛 **Creator** | up to 1,000 signatures: first seen, last seen, how busy, SOL balance, what it still holds |
| 📈 **Market** | Dexscreener: cap, liquidity, volume, buys and sells, the listing's links and boosts |
| 🔎 **Grok on X** | `x_search`, last 7 days, a few searches: posts, accounts, account ages, repeated text, the project's account, big accounts, five quotes with links |

> A line turns red when a count passes a published threshold. A card never says buy, sell, safe or rug.
